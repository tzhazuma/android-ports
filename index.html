技术说明

这些移植不是套壳，改动都在源码层面。

原生二进制

FreeCAD、Blender、Octave 的 C/C++ 核心与 Qt/SDL 界面全部针对 arm64-v8a 交叉编译；ArtCraft 系列是 Rust + egui，编译为单个 libmain.so。

走系统的文件选择器

打开与保存经由 Android Storage Access Framework。content:// URI 会被解析成真实路径（或复制进应用私有目录），保存时再把字节流回写成你选定的文件。

没有 bash 也能跑

Android 只有 toybox 的 /system/bin/sh，没有 bash。移植版在应用私有目录里放置 exec shim 并把 SHELL 指过去，命令行工具因此可用。

真实可用的图标

每个 APK 的启动图标都由软件自身的原始素材渲染，覆盖全部密度与自适应图标，而不是通用占位图。

支持这个项目

所有移植都免费开源。如果它们帮到了你，可以自愿赞助，用来覆盖测试机、编译时间和存储成本。

赞助完全自愿，不解锁任何功能，也不影响任何应用的下载与使用。
